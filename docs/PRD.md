# FreeAgent 精炼版 PRD（MVP v0.1）

## 1. 用户问题、画像与核心价值

**问题**：个人用户想用网页版大模型辅助处理本地文件，但不想购买 API、不想在本机跑模型，又担心把文件读写/系统控制交给一个不可信的模型输出。

**用户画像**：使用 Linux 桌面/开发环境的个人用户；愿意自己在浏览器登录模型网站；理解免费网页服务存在额度、地区与界面变化；希望保留对每一次文件变更的最终决定权。

**核心价值**：把「理解/规划」交给用户自选的网页模型，把「校验/执行」留在本地；用结构化协议、最小权限、逐项确认、可撤销审计，把模型能力转化为可控的小步动作。

## 2. 目标 / 非目标

**目标**：Linux CLI 启动；无付费 API；默认手动粘贴连接器；自然语言任务；一次一动作的校验—确认—执行闭环；默认 dry-run；完整审计与撤销；可中止；测试覆盖主要攻击面。

**非目标（MVP）**：付费墙/验证码/反机器人/速率限制绕过；伪装官方 API；任意 shell 或程序执行；删除文件、发消息、购买、改系统设置；读取凭据；无人值守后台任务；多智能体；自动点击/提交网页表单。

## 3. 用户流程（CLI）

| 阶段 | 用户动作 | 系统行为与关键文案 |
|---|---|---|
| 首次运行 | `freeagent setup` | 创建 `~/.freeagent`（0700）与 `~/agent-workspace`；提示「默认手动粘贴；不索取密码或 Cookie；免费额度由第三方决定」。 |
| 选择模型 | `freeagent models` | 列出 `manual`（可用）、`mock`（仅测试）、`web`（未启用/未验证）。明确「显示可用不代表网站当前可访问或有额度」。 |
| 登录 | `freeagent login manual` | 提示「无需登录：请在你自己已登录的浏览器中访问所选模型网站」；web 连接器拒绝并说明需先验证条款。 |
| 创建任务 | `freeagent "列出工作区 PDF 并归档"` | 显示任务 ID、连接器、边界（可写目录、只读目录、允许域名）、「默认 dry-run」。 |
| 模型往返 | 按提示粘贴提示词与回复（END 结束） | 展示步骤编号、动作、理由与预览；不把网页/文件/模型文本当指令。 |
| 预览确认 | 读取/打开网页/变更动作 | 显示目标路径、字节/字符数、覆盖警告、风险等级；交互终端询问 `[y/N]`；非交互终端暂停并提示 `freeagent approve <id>`。 |
| 失败 | 解析失败/越权/连接器异常/超时 | 「策略校验失败，未执行任何变更」「连接器异常：…」「达到步数上限，已安全停止」；显示原文片段（脱敏）且不做提权降级。 |
| 取消 | Ctrl-C 或 `freeagent cancel <id>` | 「已请求取消；运行中的任务不会在当前动作中途被强杀」；执行前再次检查标志位。 |
| 撤销 | `freeagent undo <id>` | 逆序撤销移动/写入/新建目录；撤销时重新过策略校验；失败即停止并报告剩余未处理。 |
| 审计 | `freeagent status/history <id>` | 每步输入摘要、动作、确认结果、执行结果、可撤销条目；敏感信息脱敏。 |

## 4. 关键终端文案（默认权限与确认）

```text
默认 dry-run：只读动作自动执行；读取内容/打开网页/写入变更均需明确确认。
本地边界：
可写工作区：/home/user/agent-workspace
允许域名：example.com

[步骤 2/8] 模型提出：fs.move {"source":"report.pdf","destination":"2025/report.pdf"}
理由：按文件日期归档
动作预览：
  - 移动：/home/user/agent-workspace/report.pdf  →  /home/user/agent-workspace/2025/report.pdf
风险：中（可撤销）
是否执行此动作？[y/N]
```

权限默认：主工作区可读写（写入仅限此目录）；`config allow-dir` 授权的目录只读；隐藏文件、凭据类文件名/后缀拒绝；域名白名单默认仅 `example.com/.org/.net`，需按需显式放开；MVP 无删除工具。

## 5. MVP 功能优先级

- **P0（已完成）**：CLI/setup；结构化动作协议与严格解析；工作区沙箱与符号链接防护；工具白名单（list/read/mkdir/move/write/browser.open）；dry-run 与逐项确认；暂停/批准/拒绝/取消；SQLite+JSONL 审计；undo；手动粘贴连接器；测试覆盖注入/越权/取消。
- **P1（部分完成）**：已增加 OpenClaw 接入用 MCP 适配层（只读默认 + prepare/commit 两阶段 + undo）和任务级 MCP 流程（`fa_task_start/reply/approve/status/list/undo`，外部智能体只做模型传输层，本地保留全部安全决策；新增 `fs.find` 安全定位文件、批准令牌哈希持久化、MCP 工具策略注解、批准人/预览哈希审计链、可配置且只能更严格的敏感路径拒绝名单、防重复动作历史、状态可续跑提示词、可执行的审计保留期清理、`doctor` 自检入口；见 `docs/OPENCLAW.md`）；待做：TUI 与更友好的差异预览、手动模式多轮粘贴体验、连接器健康诊断清单、审计保留期自动化、只读网页内容提取（需条款确认）。
- **P2（后续）**：逐站验证后的网页连接器；可插拔更多合规连接器；受限的额外工具；多工作区配置档。

## 6. MVP 验收标准（对应交接稿）

1. 干净 Linux 环境安装启动：`pip install -e . && freeagent setup && freeagent demo`。
2. 无付费 API Key，模型请求不发往开发者服务器。
3. 手动粘贴连接器可用；`freeagent demo` 用模拟模型验证闭环，不依赖真实网站。
4. 归档闭环：列文件 → 提议 → 确认 → 移动 → 写摘要（demo 与自动化测试覆盖）。
5. 无效动作/越权路径/格式错误：本地文件不变（见 `tests/test_orchestrator.py`、`tests/test_protocol.py`）。
6. 未确认时任何写入/移动不执行（见 `test_mutation_without_confirmation_changes_nothing`）。
7. 限流/登录失效/验证码/界面变化统一归为连接器异常并安全停止；web 连接器在条款验证前不可用，不提供规避。
8. 无 shell/任意程序执行；测试覆盖命令注入、路径穿越、符号链接逃逸、提示词注入与取消。
9. 每步可审计；日志脱敏，不记录 Cookie/令牌/完整敏感文件。
10. README 与本文档明确免费服务的不确定性。

## 7. 风险、隐私告知与免责声明草案

**风险**：免费额度变化；网站改版或禁止自动化；模型格式错误/幻觉；恶意网页/文档提示词注入；路径穿越与符号链接；误移动/覆盖；浏览器登录态泄露；依赖供应链。

**隐私告知**：默认只操作 `~/agent-workspace`；只上传完成任务所需的最少上下文；不读取隐藏文件、SSH 密钥、`.env`、Cookie 或环境变量；日志仅保存在本机 `~/.freeagent` 并可配置保留期；用户自行决定额外只读目录与域名白名单；手动粘贴时模型网站会看到你主动提交的内容。

**免责声明草案**：FreeAgent 不收取模型 API 费用，使用用户自行选择的免费网页服务。免费额度、地区可用性、模型版本、服务条款与界面由第三方决定并可能随时变化；本产品不保证永久免费、无限量或始终提供最强模型，也不保证任何网站可被自动化。请遵守目标网站条款，不要用本产品绕过付费墙、验证码或访问控制。

## 8. 待用户决策的问题（不擅自假定网站允许自动化）

1. 首个目标模型网站是哪一个？其当前条款是否明确允许浏览器自动化？
2. 若不允许，是否只保留手动粘贴模式作为首发（当前实现）？
3. 默认工作区路径是否为 `~/agent-workspace`？需要哪些额外只读目录？
4. 是否允许 `browser.open` 打开除示例域名外的站点？白名单如何维护？
5. 审计保留期（默认 90 天）和是否需要导出审计日志？
6. 是否需要中文以外的界面语言或无障碍输出格式？
