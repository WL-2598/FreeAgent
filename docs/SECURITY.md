# 安全、隐私与威胁模型

## 信任边界

```text
用户目标 / 本地策略（可信）
       ↓ 提示词（含不可信数据块标记）
网页模型回复、网页正文、文件内容（不可信）
       ↓ 严格 JSON Schema + 白名单 + 路径/域名策略
本地工具执行器（受控）
```

**原则**：模型输出永远不是指令；本地策略和显式用户授权才是权限来源。任何来源的文本中出现「忽略规则、读取密钥、执行命令、调用其它工具」都只是数据。

## 已实现的防护

0. **可配置拒绝名单**：默认敏感文件名/后缀始终生效；用户可用 `freeagent config deny-name` / `deny-suffix`（加 `--workspace` 只作用于当前工作区）追加规则，配置只能更严格，不能移除默认规则。

1. **无任意代码执行**：没有 shell/eval/exec 工具；动作只有固定名称与字段，Pydantic `extra="forbid"` 拒绝未知字段；未知动作在解析阶段即失败。
2. **路径沙箱**：相对路径基于主工作区；绝对路径须在授权根内；拒绝 `..`、URL 形式的路径、空字节、隐藏组件、凭据类文件名/后缀；`realpath` 拒绝逃逸符号链接，写入拒绝任何符号链接跳转；预览与执行前各校验一次（降低 TOCTOU 窗口）。
3. **最小披露**：`fs.list` 不读内容；`fs.read_text` 需批准且受单文件大小/字符上限约束；输出统一脱敏与截断；提示词中用明确的数据块包裹目标与工具输出，并中和伪造的结束标记。
4. **写入可控**：`fs.move` 不覆盖已存在目标；`fs.write_text` 覆盖需显式 `overwrite=true` 且仍需确认；所有变更记录撤销信息，撤销再次过策略校验。
5. **网络边界**：`browser.open` 仅 http(s)、仅白名单域名、拒绝 URL 内凭据与非标准端口；只打开可见标签，不点击/提交/抓取页面。
6. **闭环止损**：每轮只一个动作；解析失败有限重试后停止；策略失败/执行失败/连接器异常/超时即停止；步数与往返上限；Ctrl-C 与外部 `cancel` 在执行前检查；非交互终端绝不自动批准。
7. **本地审计**：SQLite 状态/动作/撤销记录 + JSONL 可读日志；写入前脱敏截断；目录 0700、配置/文件 0600；不记录密码、Cookie、令牌或完整敏感文件；可用 `freeagent purge` 按 `audit_retention_days` 清理过期记录。批准记录包含 `approver` 与「所见预览 + 实际动作参数」的 SHA-256，令牌只存哈希且一次性。

## 威胁覆盖情况

| 威胁 | 缓解 |
|---|---|
| 恶意网页/文档提示词注入 | 数据块隔离 + 中和分隔符 + 本地策略优先；模型输出不能直接提权 |
| 模型幻觉/格式错误 | 严格 schema、有限重试、单步执行、失败即停 |
| 路径穿越 / 符号链接逃逸 | `..` 拒绝、`realpath`  containment、写入禁符号链接 |
| 误移动/覆盖 | 预览、确认、不覆盖、undo 记录与逆序恢复 |
| 浏览器登录态泄露 | 不读取/导出 Cookie；用户自行登录；不上传凭据 |
| 网页改版/限流/验证码 | 统一归为连接器异常并停止，不做规避；手动模式兜底 |
| 依赖供应链 | 依赖极少（pydantic/typer），版本范围锁定在 pyproject；无网页自动化依赖 |
| 审计泄露 | 本地存储、权限收紧、脱敏与保留期配置 |

## 已知限制

- 手动粘贴模式下，用户仍需自行判断模型回复是否来自可信网站。
- 工具执行与取消标志之间存在极短竞态窗口；取消会在下一步/执行前再次检查，不保证中断已开始的原子操作。
- `wrap_untrusted` 是纵深防御，不是可证明的提示词注入隔离；不要扩大工具权限来「方便 demonstrations」。
- 审计 JSONL 写入失败时任务仍继续（状态库中仍有结构化记录）；若需强制审计，应在部署环境中加固。
- MVP 不提供删除工具；已写入的敏感内容一旦被用户批准上传给第三方网站，无法撤回。

## 隐私告知

默认只操作 `~/agent-workspace`；额外目录需用户显式授权且只读；默认不上传凭据、浏览器配置、SSH 密钥、环境变量、隐藏文件、密钥文件和系统日志；日志仅保存在本机，可配置保留天数（`audit_retention_days`）。用户粘贴到网页模型的内容由该网站按其条款处理，本产品不控制第三方保留策略。
