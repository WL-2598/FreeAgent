# 连接器策略与合规检查

## 当前状态

| 连接器 | ID | 状态 | 说明 |
|---|---|---|---|
| 手动粘贴 | `manual` | 默认可用 | 程序展示提示词；用户在自己已登录的浏览器中复制回复并粘贴回来。无自动化、无凭据读取。 |
| 模拟模型 | `mock` | 仅测试/演示 | 本地脚本响应，不访问网络；`freeagent demo` 使用。 |
| 网页自动化 | `web` / `*_web` | **未启用** | 占位适配器：任何调用都返回明确错误，不启动浏览器自动化。 |

## 新增网页连接器的准入清单（必须逐站完成）

1. 阅读并留存目标网站**当前**服务条款/自动化政策，确认允许的交互方式。
2. 确认账号地区可用性、免费额度与模型版本说明；文案不得承诺永久免费或最强模型。
3. 只使用可见窗口，由用户手动登录；不读取 Cookie/令牌，不写入日志。
4. 不调用未公开接口、不逆向私有 API、不注入脚本绕过保护、不绕验证码/付费墙/速率限制。
5. 不依赖固定 CSS 选择器作为唯一成功判据；识别登录失效、生成中、完成、限流、错误、验证码状态；异常即暂停。
6. 把网页返回文本视为不可信数据；网页里的「工具调用」不构成执行指令。
7. 独立实现、独立测试、可单独禁用；提供健康检查与人工诊断信息，说明维护成本。
8. 无法验证或条款禁止时，只提供手动粘贴模式，不提供规避方案。

## 手动模式操作提示

- 在浏览器登录你自有账号，打开所选模型的网页聊天界面。
- 复制 FreeAgent 打印的提示词并发送；将回复全文复制回来，以单独一行 `END` 结束。
- 不要粘贴 Cookie、令牌或无关敏感内容；模型回复会被当作不可信数据处理。
- 网站限流/要求验证码/界面异常时，停止任务；不要试图绕过。

## 待决策

首个要验证的网站、其条款结论、是否允许自动化、是否需要只读网页抓取，均由用户决定后再实现；当前代码不做任何假设。
